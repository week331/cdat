# CDAT論文の検算プログラム（2026-10-05）

「累積差額調整税 (CDAT)：累積差額のリアルタイム管理に基づく消費課税の設計仮説」（2026-10-05版）の16節と付録Bの数値を再現するプログラムです。

## 必要なもの

Python 3 だけです（標準ライブラリのみ。作成と確認は Python 3.11.15 で行いました）。

## ファイル

| ファイル | 内容 | 論文の対応箇所 |
|---|---|---|
| scenarios.py | 現行VATとCDATの更新則を実装し、事例ごとに、時点ごとの国庫の受払い、国庫の受領累計、発生税収、預かり、立替を計算する。各行で「国庫の受領累計 = 発生税収 + 立替 − 預かり」を assert で検算する。表16.7(c)では、16.7節の取引列に仕入税額の扱いの異なる続きを加え、最終的に国庫に残る仕入税額 K と税収不足額 L を求める | 15節、16節、付録B.1、B.2、B.3.6 |
| appendix_b.py | 回帰テストの表を計算する | 付録B.3.1〜B.3.5、表B.3.6(c) |
| tables_lib.py | 表と、付録B.1の各行の計算式を作る。計算式の左辺と右辺が一致することを確かめる。表16.7(c)では、16.7節の本文の比較と、同じ計算による4.1節の例も確かめる | 16節、付録B.1、4.1節の例 |
| print_tables.py | 論文と同じ順に表を出力する | 16節、付録B.1〜B.3 |
| check_late_hold_b33_b34.py | 20万通りの無作為な検査を2種類行う | 付録B.3.3、B.3.4 |
| check_random_b4.py | 600,000時点の無作為な検査を行う | 付録B.4、命題3 |
| expected/ | 上の三つの実行用プログラムの出力 | |
| run_all.sh | すべて実行し、出力を expected/ と比べる | |

## 使い方

```
sh run_all.sh
```

個別に実行する場合は `python3 print_tables.py` のようにします。check_random_b4.py は1分40秒ほど（Python 3.11）、ほかは数秒で終わります。

## 再現性

- 乱数は Python 標準の random モジュールを、種を固定して使います。種は check_random_b4.py が 20261004、check_late_hold_b33_b34.py が 20261003 と 9 です。同じ版の Python では同じ出力になります。他の版でも同じ乱数列になることが期待されますが、確認したのは 3.11 です。
- 金額は fractions.Fraction による有理数で計算しており、丸め誤差はありません。
- 検査の条件が一つでも成り立たなければ AssertionError で止まります。

## 期待される出力の主な数値

- 付録B.3.3：遅れて記録した方が有利になった数は、記録時点のCDを用いる規則で 74,752、取引時点と記録時点のCDの小さい方を用いる規則で 27,428、β_k = 0 の規則で 0。β_k = 0 の規則で増える納付額は、取引時に記録していれば受けた自動還付の額を超えなかった。
- 付録B.3.4：保留中の事後訂正をそれが生じた時点で行う場合、確認時に処理した場合より有利になった数は、確認終了時のCDをそのまま上限とする規則で 59,059、9節の規則で 0。9節の規則は、事後訂正のない 71,412 通りのすべてで、確認時に処理した場合と一致した。事後訂正を確認終了時にまとめて行う場合（付録B.3.4の表と同じ扱い）は、それぞれ 41,531 と 0。
- 付録B.4：600,000時点（取引時に記録されない販売 29,978 件、保留中の輸出の確認 10,041 件を含む）で、恒等式と不変条件がすべて成り立った。命題3の事業者ごとの不等式を 3,600,000 回検査した。
- 付録B.1、B.2、B.3.6 の事例の計算式 225 個で、左辺と右辺が一致した。
- 表16.7(c)：K と税収不足額 L は、現行VATで還付が審査を通れば 0 と 900、否認または申告しなければ 400 と 500、共謀する事業者へ控除を移せば 0 と 900。CDATでCDが還付の契機を得なければ 400 と 500、後の記録された販売または審査付き還付で回収されれば 0 と 900、共謀する事業者へCDを移せば 0 と 900。旧版の即時清算では 0 と 900。各行で L = S_u − K（S_u = 900）。取引列の計算式は 117 個。
- 4.1節の例（仕入の税額10,000、記録された販売なし、S_u = 15,000）の税収不足額：現行VATで還付が審査を通れば 15,000、還付申告を行わなければ 5,000、CDATでCDが契機を得なければ 5,000、審査付き還付が認められれば 15,000、旧版の即時清算では 15,000。

## 注意

無作為な検査は、論文で定めた更新則と恒等式が実装の上で矛盾しないことの検査であり、制度が正しいことそのものの証明ではありません（付録B.4）。
